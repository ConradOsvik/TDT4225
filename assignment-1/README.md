# TDT4225 Assignment 1

Typst report scaffold for Exercise 1 (theory). The original assignment is in
[`reference/exercise1.pdf`](reference/exercise1.pdf). The report follows its 17
questions in order, including the subparts of questions 15 and 17. The answers
draw on the course PDFs in `../../docs/TDT4225` and cite the relevant chapters,
pages, or slides in the report.

## Build

Requires [Typst](https://typst.app/docs/).

```sh
make report
```

This writes `output/pdf/assignment-1.pdf`. Run `make watch` to rebuild it while
editing `report/main.typ`.
